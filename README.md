# Meta Ads dashboard

Dashboard for Meta advertising that explains every metric in plain language. The owner sees spend, reach, cost per result and frequency, and gets a short list of what needs attention now.

## What it does

- Summary for a chosen period, with hourly charts.
- Each metric shows its Meta name, a translation and a short explanation.
- Rules flag problems, for example rising frequency or cost per result.
- Commands run actions in the ad account right from the dashboard.

## Stack

Next.js, React, TypeScript, shadcn/ui, Recharts, TanStack Table, Python API, Meta Marketing API.
